# Zeiterfassung

Einfache Stempeluhr im iOS-Liquid-Glass-Look. Läuft komplett offline im Browser.

- Kommen / Gehen per Knopfdruck, 1 Stunde Pause wird automatisch abgezogen
- Archiv mit jedem Tag (bearbeiten, nachtragen, löschen)
- Stundenkonto mit Plus-/Minusstunden, Anwesenheitstage, Berufsschule, Urlaub, Krank
- Sicherung speichern / laden (JSON) zum Übertragen zwischen Geräten
- Keine Server, keine Anmeldung – alle Daten bleiben auf dem Gerät (localStorage)

## Benutzen
- **PC/Laptop:** `index.html` doppelklicken (Chrome oder Edge).
- **Handy:** Ordner auf einen HTTPS-Webspace legen (z. B. GitHub Pages), einmal öffnen,
  „Zum Home-Bildschirm“ – danach läuft die App offline.
